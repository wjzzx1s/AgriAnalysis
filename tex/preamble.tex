% 部（Part）样式：ctexart 无 chapter，故用 titlesec 定制 \part
% \thepart 在 ctexart 下是罗马数字（I、II），直接交给 \zhnumber 会被解析为 0，
% 因此必须先取 \arabic{part}。
% 部分标题页：标签与标题均水平居中，并在版心内垂直居中（before-space 取版心高度的 0.42 倍）。

  {\centering\heiti\zihao{2}}
  {\zihao{3}\sffamily 第\,\zhnumber{\arabic{part}}\,部分}
  {12pt}
  {}
  []
