# 公司事实底稿（data/facts/）格式说明

本目录存放报告第二部分“农业上市公司画像”所用的**逐家公司事实底稿**：
每家公司一个文件 `data/facts/<6 位证券代码>.yaml`（如 `data/facts/002124.yaml`）。

底稿只记录**有公开来源的事实**，由调查脚本/人工检索后写入，报告生成脚本
（`scripts/make_company_profiles.py`）读取后与财务、行情数据合并成画像正文。
**任何没有来源 URL 的内容都不得写入**；查不到就写 `"未查得"` 或留空列表。

## YAML 结构

```yaml
代码: "002124"
名称: "天邦食品"
定位: "30—80 字的定性定位（公司在行业中的位置、主业、当前处境），不含编造数字"
沿革:                        # 公司发展史上的节点，3—8 条
  - 年: "1996"
    事件: "在浙江余姚成立，以水产饲料起家"
    来源: "https://..."
主营与结构:                  # 业务结构、主营构成、产能布局的定性事实
  - 事件: "2020 年起生猪养殖成为第一大收入来源"
    来源: "https://..."
融资历史:                    # IPO、定增、可转债、公司债、配股、并购、借款、战投、重整投资款
  - 时间: "2007-04"
    方式: "IPO（深交所中小板）"
    规模: "2.58 亿元"
    用途: "扩大饲料产能"
    说明: ""                 # 补充说明，可为空字符串
    来源: "https://..."
风险与困境:                  # 重整/预重整、债务违约、诉讼、退市风险、净资产为负、处罚、质押
  - 时间: "2024-03-18"
    事项: "董事会通过向法院申请重整及预重整的议案"
    来源: "https://..."
战略与转型:                  # 并购、剥离、跨界、扩产、海外布局、成本战略
  - 时间: "2025-05-08"
    事项: "与产业投资人签署《重整投资协议》"
    来源: "https://..."
融资需求线索:                # 公开信息中关于“下一步融资”的线索：拟定增预案、重组方案、授信、发债额度
  - 时间: "2026-09-18"
    事项: "与产业投资人解除重整投资协议，重新公开招募重整投资人（报名截止 2026-10-15）"
    来源: "https://..."
其他要点:                    # 其余对画像有用的要点（技术、成本、股东结构、行业排名、产能数据等）
  - 要点: "2026 年上半年生猪出栏量约 xxx 万头"
    来源: "https://..."
来源:                        # 本次调查使用过的主要页面，去重后列出
  - "https://..."
```

## 写作与检索要求

- 每条 `来源` 必须是真实可访问的 URL（`http`/`https`），且是**实际打开过**（`web_extract`）
  或搜索结果中明确包含该事实的页面。
- 金额、日期、比例必须与来源一致，不得四舍五入改变量级，不得跨期混用。
- 宁少勿错：无法核实的条目直接省略；整家公司查不到融资历史时，`融资历史: []`。
- 时间字段：能取到具体日期用 `时间: "YYYY-MM-DD"`，只能取到月份用 `"YYYY-MM"`，
  只能取到年份时写在 `沿革` 的 `年` 字段。
- 检索优先顺序：公司公告/巨潮资讯、公司年报与半年报摘要、证券时报/上海证券报/中国证券报、
  新浪财经/东方财富/同花顺、财联社/每日经济新闻、地方政府与国资网站。
